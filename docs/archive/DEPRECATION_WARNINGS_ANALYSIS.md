## 🔍 Detailed Analysis of Warnings

### **Warning Category 1: Pydantic `.dict()` Deprecation**

**Count**: ~150+ warnings

**Warning Message**:
```
PydanticDeprecatedSince20: The `dict` method is deprecated; use `model_dump` instead.
```

**Root Cause**:
Pydantic 2.0+ deprecated `.dict()` in favor of `.model_dump()` for clarity.

**Code Locations** (5 files):

1. **`app/services/user_service.py:226`**
   ```python
   # Current (deprecated):
   update_data = user_update.dict(exclude_unset=True)

   # Should be:
   update_data = user_update.model_dump(exclude_unset=True)
   ```

2. **`app/services/user_service.py:306`**
   ```python
   update_data = user_update.dict(exclude_unset=True)
   ```

3. **`app/services/user_preference_service.py:51`**
   ```python
   # Preferences update
   update_data = preferences.dict(exclude_unset=True)
   ```

4. **`app/services/enrollment_service.py`**
   - Multiple `.dict()` calls

5. **`app/services/progress_service.py`**
   - Multiple `.dict()` calls

6. **`app/services/content_service.py`**
   - Multiple `.dict()` calls

**Impact**: ⚠️ **None** - `.dict()` still works, just deprecated

**Timeline**: Will be removed in Pydantic 3.0 (not yet released)

---

### **Warning Category 2: Python `datetime.utcnow()` Deprecation**

**Count**: ~100+ warnings

**Warning Message**:
```
DeprecationWarning: datetime.datetime.utcnow() is deprecated and scheduled for removal
in a future version. Use timezone-aware objects to represent datetimes in UTC:
datetime.datetime.now(datetime.UTC).
```

**Root Cause**:
Python 3.12 deprecated `datetime.utcnow()` in favor of timezone-aware datetime objects.

**Code Locations**:

1. **`app/schemas/enrollment.py:40`**
   ```python
   # Current (deprecated):
   enrollment_date: datetime = Field(default_factory=datetime.utcnow)

   # Should be:
   from datetime import datetime, UTC
   enrollment_date: datetime = Field(default_factory=lambda: datetime.now(UTC))
   ```

2. **SQLAlchemy Models** (indirect)
   - Default timestamps using `datetime.utcnow`
   - Generated by SQLAlchemy, not directly in our code

3. **Pydantic Validators** (indirect)
   - Pydantic 2.5.0 internally uses `utcnow()` for validation
   - Fixed in Pydantic 2.10+

**Impact**: ⚠️ **None** - Still works, scheduled for removal in Python 3.13+

**Timeline**: Will be removed in Python 3.15+ (not soon)

---
